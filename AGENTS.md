# AGENTS.md

Контекст репозитория — см. [README.md](README.md). Кратко: это личная база знаний об опыте использования и разработки ИИ-агентов в рамках проекта supagent (соседний репо `../supagent`): заметки, черновики статей и докладов, связанные материалы.

## Правила для агентов

- Пиши по-русски, Markdown; технические термины можно оставлять на английском.
- Это не кодовая база: не добавляй сборку, зависимости и т. п. без запроса.
- Структура плоская, без обязательных папок; не создавай папки без необходимости.
- Не включай секреты и конфиденциальные данные; рабочие фрагменты обезличивай.
- Для фактов о supagent сверяйся с кодом в `../supagent`, не выдумывай.
- Сохраняй авторский голос и мысли пользователя; не переписывай черновики без запроса.
