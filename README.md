# supagent-posting

Личная база знаний о моём опыте использования ИИ-агентов и разработки ИИ-агентов — в контексте работы над **supagent** (соседний репозиторий `../supagent`).

## Назначение

Здесь копятся:

- заметки и наблюдения (что работает, что нет, грабли, паттерны);
- черновики статей и докладов;
- прочие связанные материалы (схемы, конспекты, ссылки, примеры промптов и диалогов, тезисы).

Репозиторий — не код продукта, а источник материала для публикаций и выступлений.

## Связь с supagent

Код и история разработки живут в соседнем репо `supagent`. Здесь — осмысление этого опыта. При упоминании конкретных решений полезно ссылаться на соответствующие коммиты/файлы/PR в supagent.

## Структура

Жёсткой структуры нет: файлы лежат плоско, папки появляются только когда без них становится неудобно.

## Соглашения

- Язык материалов: русский (технические термины можно оставлять на английском).
- Формат: Markdown.
- Заметки лучше датировать (в имени файла `YYYY-MM-DD-тема.md` или в заголовке).
- Не хранить секреты, токены и конфиденциальные данные работы; при использовании фрагментов рабочего кода/диалогов — обезличивать.
